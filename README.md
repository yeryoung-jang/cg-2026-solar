## 3주차 - 그래픽스 파이프라인과 셰이더

### Task 1 - 공과 바닥 장면 만들기

- 바닥 위에 떠서 회전하는 공을 구현했습니다.
- 이동과 회전의 순서를 바꾸어 공의 움직임을 비교했습니다.
- 프래그먼트 셰이더를 수정하여 밝기가 단계별로 나뉘는 툰 셰이딩을 적용했습니다.
- [Task 1 실행하기](https://yeryoung-jang.github.io/cg-2026-solar/week3/task1.html)

### Task 2 - 살아 있는 행성 만들기

- 서로 다른 프래그먼트 셰이더를 적용한 얼음 행성과 벚꽃 행성을 구현했습니다.
- 꽃잎의 회전값과 얼음 표면의 법선 계산을 수정하면서 셰이더 결과를 비교했습니다.
- 얼음 셰이더에서 uniform 선언이 빠져 화면이 나오지 않는 문제를 확인하고 수정했습니다.

### 이번주 추가한 것과 막혔던 점

- 구와 바닥으로 3차원 장면을 만들고, 변환 순서에 따라 회전 중심과 움직임이 어떻게 달라지는지 비교했습니다.
- 프래그먼트 셰이더를 수정해 툰 셰이딩을 적용하고, 얼음 행성과 벚꽃 행성에는 서로 다른 표면 무늬와 색을 구현했습니다.
- 꽃잎이 행성 표면에 고정되지 않고 계속 회전하거나 얼음 행성이 화면에 나오지 않는 문제가 있었고, AI의 도움을 받아 회전 방식과 `uModel` 선언을 수정해 해결했습니다.

### AI 활용 기록

| 프롬프트 요약 | AI 결과 | 내가 한 일 |
| --- | --- | --- |
| 벚꽃잎을 서로 다른 랜덤 방향으로 배치하고 행성이 회전해도 꽃잎 방향은 표면에 고정되도록 구현 | 처음 제안된 코드에서는 모든 꽃잎에 같은 시간 기반 회전값이 적용되어 꽃잎 22개가 서로 다른 방향으로 고정되지 않고 같은 각도 변화가 반복됨. 행성이 한 번 자전한 뒤에도 같은 방향 배열이 다시 반복되어 자연스럽지 않았음. | 원하는 것은 각 꽃잎이 처음부터 서로 다른 방향을 가지되 그 방향은 행성 표면에 고정되는 것이었기 때문에 시간에 따른 회전값을 제거함. 꽃잎마다 서로 다른 고정 각도를 갖도록 `petalAngles[i]`를 사용해 수정 |
| 얼음 행성 표면을 더 얼음처럼 표현 | 얼음판 사이에 불규칙한 균열을 만드는 방식을 제안받았지만 실행 결과가 자연스러운 얼음보다 육각형 타일이나 등껍질처럼 보여 원하는 결과와 달랐음. | 제안된 균열 표현은 사용하지 않고 기존 코드로 되돌린 뒤 노이즈로 표면 높낮이를 만들고 법선을 변화시키는 방식으로 다시 구현 |

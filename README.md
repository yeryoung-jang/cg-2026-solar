### 이번주 추가한 것과 막혔던 점

- 세 물체의 변환을 설계하고 변환 순서에 따라 움직임과 거리가 어떻게 달라지는지 비교했습니다.
- 실제 비율에서는 인공위성이 너무 작게 보여서 Task 3에서는 크기와 거리를 조절해 물체를 구분하기 쉽게 만들었습니다.
- Task 1 실행 화면이 파란색으로만 보이는 문제는 AI의 도움을 받아 카메라 거리와 확대축소 범위를 장면 크기에 맞게 수정했습니다.

- AI 설명을 수정한 사례

AI는 처음에 Task 3에서 달과 위성의 거리를 모두 줄였다고 설명했습니다. 달은 한 화면에 보이게 하기 위새 거리를 줄인 것이 맞지만 지구 반지름을 1로 놓으면 위성의 실제 거리는 약 1.11이고 Task 3의 설정값은 2입니다. 따라서 위성은 더 멀리 배치한 것으로 설정했으므로 보고서의 설명을 수정했습니다.

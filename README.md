- 처음에는 P5 주변의 벽을 숨기는 방법도 적용했지만 내부 구조가 한꺼번에 보여 화면이 더 복잡해졌기 때문에 이 방식은 사용하지 않았습니다.

### Task 2 - 격리된 행성과 붉은 경고 비콘

- 검은 이상 지점이 발생한 파란 행성과 주변을 공전하는 붉은 경고 비콘을 구현했습니다.
-파란색 Directional Light와 붉은색 Point Light를 함께 적용하여 두 광원의 차이를 표현했습니다.
- 행성에는 표면 요철과 약한 정반사를 적용하고, 비콘에는 자체발광과 하이라이트를 적용해 서로 다른 재질을 표현했습니다.
- 비콘이 공전하면서 밝기가 반복적으로 변하도록 구현하고 `1`, `2` 키로 두 광원을 개별적으로 켜고 끌 수 있도록 했습니다.
- 두 광원이 모두 켜진 상태와 각각 하나만 켜진 상태를 비교했습니다.
- [Task 2 실행하기](https://yeryoung-jang.github.io/cg-2026-solar/week5/task2.html)

### 이번주 추가한 것과 막혔던 점

- Diffuse, Ambient, Specular와 거리 감쇠를 적용하면서 각 조명 요소가 물체의 밝기와 입체감에 어떤 영향을 주는지 확인했습니다.

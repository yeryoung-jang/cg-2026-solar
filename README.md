## 2주차 - 지구·달·인공위성의 변환 설계

지구, 달, 아리랑 3호의 크기와 거리를 조사하고 이동, 회전, 크기 변환을 조합했습니다. 또한, 실제 비율로 배치한 결과와 전체를 같은 배율로 줄인 결과, 화면에서 보기 쉽게 크기와 거리를 조절한 결과를 비교했습니다.

- 세 물체의 변환을 설계하고 변환 순서에 따라 움직임과 거리가 어떻게 달라지는지 비교했습니다.
- 실제 비율에서는 인공위성이 너무 작게 보여서 Task 3에서는 크기와 거리를 조절해 물체를 구분하기 쉽게 만들었습니다.
- Task 1 실행 화면이 파란색으로만 보이는 문제는 AI의 도움을 받아 카메라 거리와 확대축소 범위를 장면 크기에 맞게 수정했습니다.

## 3주차 - 그래픽스 파이프라인과 셰이더

- [3주차 보고서](week3/week3.md)

### Task 1 - 공과 바닥 장면 만들기

- 바닥 위에 떠서 회전하는 공을 구현했습니다.
- 이동과 회전의 순서를 바꾸어 공의 움직임을 비교했습니다.
- 프래그먼트 셰이더를 수정하여 밝기가 단계별로 나뉘는 툰 셰이딩을 적용했습니다.
- [Task 1 실행하기](https://yeryoung-jang.github.io/cg-2026-solar/week3/task1.html)

### Task 2 - 살아 있는 행성 만들기

- 서로 다른 프래그먼트 셰이더를 적용한 얼음 행성과 벚꽃 행성을 구현했습니다.
- 꽃잎의 회전값과 얼음 표면의 법선 계산을 수정하면서 셰이더 결과를 비교했습니다.
- 얼음 셰이더에서 uniform 선언이 빠져 화면이 나오지 않는 문제를 확인하고 수정했습니다.

### 이번주 추가한 것과 막혔던 점

- 구와 바닥으로 3차원 장면을 만들고, 변환 순서에 따라 회전 중심과 움직임이 어떻게 달라지는지 비교했습니다.
- 프래그먼트 셰이더를 수정해 툰 셰이딩을 적용하고, 얼음 행성과 벚꽃 행성에는 서로 다른 표면 무늬와 색을 구현했습니다.
- 꽃잎이 행성 표면에 고정되지 않고 계속 회전하거나 얼음 행성이 화면에 나오지 않는 문제가 있었고, AI의 도움을 받아 회전 방식과 `uModel` 선언을 수정해 해결했습니다.

## 4주차 - 카메라와 투영

### 기본 버전 관찰

- 기본 트랙볼 카메라를 이용해 P1~P6 명판의 정보를 직접 찾고 O1~O2의 형태를 비교했습니다.
-작은 명판을 읽기 위해 반복적으로 회전하고 확대해야 하고 확대하면 명판이 전체 구조에서 어디에 있는지 파악하기 어려웠습니다.
- [Baseline 실행하기](https://yeryoung-jang.github.io/cg-2026-solar/week4/baseline/)

### 개선한 관찰 인터페이스

- P1~P6 버튼을 추가해 원하는 명판의 위치와 방향으로 카메라가 바로 이동하도록 구현했습니다.
- 각 명판의 크기와 주변 구조가 다르기 때문에 지점별로 관찰 거리를 따로 조정했습니다.
- P5는 주변 위치와 작은 명판을 동시에 확인하기 어려워 메인 화면과 별도로 명판을 확대하는 포커스 렌즈를 추가했습니다.
- O1은 +z 방향에서 바라보는 전면 직교 투영, O2는 +x 방향에서 바라보는 오른쪽 측면 직교 투영으로 구현했습니다.
- 비교 모드에서는 관련 없는 명판과 일부 기구, 장비를 숨기고 전체 보기를 누르면 다시 복원되도록 했습니다.
- [Improved 실행하기](https://yeryoung-jang.github.io/cg-2026-solar/week4/improved/)

### 기본 버전과 개선 버전 비교

- 기본 버전에서는 8개 관찰 항목 중 P1~P6은 모두 확인했지만 O1~O2는 판단을 보류하여 총 6개를 완료했습니다.
- 개선 버전에서는 P1~P6과 O1~O2를 모두 확인하여 총 8개를 완료했습니다.
- 전체 관찰 시간은 `156초`에서 `41초`로 줄었고 기록한 조작 횟수는 `206회`에서 `8회`로 줄었습니다.
- 직교 투영을 사용하면서 원근 효과의 영향을 받지 않고 O1의 폭, 높이와 O2의 돌출 정도를 비교할 수 있었습니다.

### 이번주 추가한 것과 막혔던 점

- P1~P6의 위치와 방향 데이터를 이용해 관찰 버튼을 구현하고 대상에 따라 카메라 거리와 회전 중심을 다르게 설정했습니다.
- P5는 명판을 가까이 보여주면 주변 위치가 보이지 않고 멀리 보여주면 글자가 읽히지 않는 문제가 있어 메인 화면과 포커스 렌즈를 함께 사용하는 방식으로 수정했습니다.
- 처음에는 P5 주변의 벽을 숨기는 방법도 적용했지만 내부 구조가 한꺼번에 보여 화면이 더 복잡해졌기 때문에 이 방식은 사용하지 않았습니다.
- P5 화면을 구현했을 때 확대축소가 되지 않는 문제가 있어 메인 화면은 기존 트랙볼 카메라를 유지하고 포커스 렌즈만 별도 고정 카메라로 렌더링하도록 수정했습니다.
- P5 상태에서 전체 보기를 눌렀을 때 포커스 렌즈가 남아 있는 문제가 있었고 전체 보기에서 렌즈와 'viewer.render'에 설정된 P5 전용 렌더링 상태를 함께 초기화하도록 수정했습니다.
